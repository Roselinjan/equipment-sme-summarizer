​# Equipment SME Assistant 🏭

 An AI-powered Equipment SME Assistant built on AWS that helps field technicians and equipment experts quickly summarize incident log reports using Generative AI.

 ## 🔗 Live Demo

https://equipment-sme-summarizer-uxpgartoxav3eykuakgc63.streamlit.app/

 
 ## 🏗️ Architecture

User → Streamlit UI → API Gateway → Lambda → Amazon Bedrock → AI Summary

 
## 🛠️ Tech Stack

- Amazon Bedrock (Nova Pro)

- AWS Lambda (Python + boto3)

- AWS API Gateway

- Streamlit

- IAM, CloudWatch

 

## ✨ Features

- Upload incident log reports as text

- Get instant AI generated summary

- Serverless architecture

- Production ready deployment
